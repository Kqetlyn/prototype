Event log

    Run it on a tablet
    1. Save this file as index.html and put it in a GitHub repository.
    2. In the repository, open Settings → Pages and deploy from your main branch. You get an https link.
    3. Open that link in Chrome on an Android tablet, tap Start camera and allow the camera. The gesture model downloads the first time.
    4. Camera, gestures and Bluetooth do not run inside the Claude preview. Tapping, the simulated wrench and QR from a photo do.
    What is simulated

    Wrench readings, the tool register, the staff badge scan and the panel position (the overlay is fixed on screen; a later version anchors it to markers on the real panel). Torque values and the bolt order are demo values, not from a maintenance manual.

    ESP32 wrench (stage 5)

    Advertise as TT-TW0042 with the Nordic UART service 6e400001-b5a3-f393-e0a9-e50e24dcca9e. Send lines on the TX characteristic: TQ:25.3 for a reading and ID:TW-0042 when asked with ID?. Switch the wrench mode to Bluetooth before connecting.

    Keyboard shortcuts

    T or Space: simulated pull · N / B: next / previous bolt · G: gestures on/off · P: photo · F: finish task
