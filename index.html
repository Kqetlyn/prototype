    Event log

      Run it on a tablet
      1. Open the GitHub Pages link in Chrome on an Android tablet.
      2. Tap Start camera and allow the camera. The gesture model downloads the first time.
      3. Camera, gestures, Bluetooth and file downloads do not run inside the Claude preview. Tapping, the simulated wrench and QR or stripe photos do.
      What is simulated

      Wrench readings, running torque, live torque curves, battery and signal, drops and overloads, the tool register and history, bench check results, the heat sensor, staff badge scans, the digital twin's past visits and the panel position (the overlay is fixed on screen; a later version anchors it to markers on the real panel). Torque values, minimum running torque, bolt order, part lots and aircraft registrations are demo values, not from a maintenance manual. The torque stripe check only looks for the stripe colour; a trained model would also check alignment.

      Real Bluetooth tools

      Best fit: Norbar NorTronic (open plain-text Bluetooth protocol: set targets, read results, stream live torque, read calibration date, disable the tool). Also Tohnichi CEM3-G-BTD/BTA (duplex limits), Stahlwille MANOSKOP 766 DAPTIQ HCT, and Sylvac or Mitutoyo Bluetooth gauges. Tools that act as Bluetooth keyboards (HID) can't be reached by Web Bluetooth; their readings can be typed into a focused field instead.

      ESP32 wrench (stage 5)

      Advertise as TT-TW0042 with the Nordic UART service 6e400001-b5a3-f393-e0a9-e50e24dcca9e. Send lines on the TX characteristic: LV:12.4 live torque samples, RT:2.6 running torque, TQ:27.8 peak torque at the wrench drive, BT:84 battery %, EV:DROP and EV:OVER from the motion sensor, and ID:TW-0042 when asked with ID?. With a crowfoot fitted in line, the app converts the drive reading to torque at the fastener.

      Keyboard shortcuts

      T or Space: simulated pull · N / B: next / previous bolt · G: gestures on/off · P: photo · F: finish · O: inspector confirms bolt
